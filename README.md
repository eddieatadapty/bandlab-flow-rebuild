# BandLab Growth Audit

**Live → https://eddieatadapty.github.io/bandlab-flow-rebuild/**

Five ideas to turn more BandLab users into subscribers, each built into a clickable version of BandLab's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Offer Membership at the end of onboarding, in their role’s words | +10–20% CR to purchase |
| 02 | Let them pick a premium beat before the ask | +5–15% CR to purchase |
| 03 | Test three offers on one paywall, without a release | +10–15% ARPU (annual mix) |
| 04 | Catch the people who close the paywall | +10–15% ARPU |
| 05 | Ask for notifications after the paywall | +5–10% CR to purchase |

Every price, rating and feature comes from BandLab's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for BandLab. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
